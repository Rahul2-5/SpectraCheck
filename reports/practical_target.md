# Practical-use target for Phase 7

Status: **Pending team and supervisor agreement.** This file is intentionally
not assigned a numerical target by the implementation agent.

Before Phase 7, the team should record:

- The minimum validation accuracy at which the local prototype would be useful
  for this single Stable Diffusion v1.5 dataset.
- The rationale and intended use for that target.
- The team members and supervisor who agreed to it, with the decision date.

This practical-use judgment is separate from statistical significance. The
target must be agreed before the sealed test set is opened, then included in
the Phase 7 freeze provenance. Do not use a test result to set or revise it.
